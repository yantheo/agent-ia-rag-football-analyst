Comparaison des modèles v1 / v2 / v3 (= moyenne v1/v2)

Outil de diagnostic (pas une page publique). Pour chaque match, v1 (v1-poisson-k6, référence historique) et v2 (v2-elo-k13 : Elo des clubs + Poisson, référence, production du 03/11 au 05/11) sont calculés dans la même passe, sur les mêmes données. v3 = moyenne v1/v2 (moy-v1v2-w50, en production sur Meilleurs Paris depuis le 05/11 ; « =v2 » : v1 incalculable, repli sur la v2 comme en prod) : P(v3) = ½·P(v1) + ½·P(v2), issue par issue.

Marché : saisir les cotes 1 / N / 2 d'un match -> probabilités sans marge (méthode de la puissance) et écart max avec v2 / v3 en points (en or si ≥ 10 pts). Les cotes restent dans ce navigateur (localStorage) : « Exporter CSV » pour les journaliser. Un gros écart avec le marché signale d'abord une erreur probable du modèle, pas une valeur.

Espérance = P(1) + ½·P(N) : c'est elle (pas P(1)) qui se compare à la cible Elo 1/(1+10^(−dE/400)). Lignes surlignées = le favori change de camp entre v1 et v2. « Champions League » = équipes de championnats différents. Elo : instantané ClubElo versionné (elo-clubs.json).

Saisir le score final de chaque match. Pour chaque modèle : probabilité donnée à l'issue réelle, ✓ si c'était son favori. Les prédictions utilisées sont celles figées avant le match (fichier predictions-figees.json, ou figées automatiquement dans ce navigateur quand la page est ouverte avant le coup d'envoi). Sinon, la page recalcule avec les stats actuelles, qui incluent peut-être déjà le match : ligne marquée « recalculée », à prendre avec prudence. Brier : 0 = parfait, 0,667 = 1/3 partout ; plus bas = meilleur. Bilan v1 / v2 / v3 sur les matchs où les trois ont une prédiction. Mon prono : tes probabilités en % (ex. 30 / 25 / 45, normalisées si la somme n'est pas 100), à saisir avant le coup d'envoi : un prono saisi après le début du match est marqué « après coup » et exclu du bilan ; une fois le match commencé, un prono valide est verrouillé.
